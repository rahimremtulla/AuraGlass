# ✨ AuraGlass Home Assistant Dashboard

A refined adaptation of djmalaka's <a href="https://github.com/djmalaka/Abode-Dashboard/" target="_blank">Abode Dashboard</a>, updated with tweaks and compatibility fixes for newer versions of Home Assistant.

![AuraGlass Home Assistant Dashboard](https://github.com/user-attachments/assets/3071b50b-5399-48f1-be33-2d8369455ed4)

## 🙏 Acknowledgements

AuraGlass is based on the excellent original **Abode Dashboard** created by djmalaka. Many thanks to him for creating and sharing his work, which provided the foundation for this project.

This version includes modifications and compatibility updates to help the dashboard work with newer versions of Home Assistant, while retaining the look and feel of the original design.

## ⚙️ Customisation & Compatibility

The dashboard has been tailored to my own Home Assistant setup. It relies on specific helpers, sensors, custom logic, and UI behaviour, so the YAML configuration will **not work out of the box on other systems**.

You may need to adapt entity IDs, helpers, sensors, and other configuration to suit your own installation.
